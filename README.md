## 📌 About the Project

SP Artisan Coffee Website is a responsive coffee shop website built using HTML, CSS, JavaScript, and PHP.

I built this project with a long-term vision of starting my own coffee café business in the future. This website represents my idea of how my real business website could look and function.

This project also helped me improve my frontend and backend development skills and understand how real-world business websites are designed and deployed.

## 🎯 Purpose of This Project

- To improve my web development skills (HTML, CSS, JavaScript, PHP)
- To create a real-world business website concept
- To prepare a digital base for my future coffee café startup idea
- To gain experience in website deployment (Vercel)
  
## 🚀 Features

- Responsive and modern UI design
- Home, About, Products, and Contact sections
- Smooth navigation and animations
- Contact form using PHP backend
- Coffee product showcase section
- Clean and user-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP
- Vercel (Hosting)
